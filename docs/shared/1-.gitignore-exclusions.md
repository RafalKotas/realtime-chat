# .gitignore

Tells Git which files and directories to ignore when you make a commit.

---

## Basic patterns

1. Filename

```gitignore
config.yml
```

ignores: `config.yml` file

---

2. Folder

```gitignore
node_modules/
```

ignores: all files in any folder named `node_modules`

---

3. All files with extension

```gitignore
*.log
```

ignores: `app.log`, `error.log`, `debug.log`, ...

4. Relative path

```gitignore
backend/target/
```

ignores: `target` folder with files inside only in `backend/` folder

BUT

```gitignore
target/
```

ignores **ALL** `target/` in the entire repo 

5. Difference: `/` at the beginning

- Without `/`

```gitignore
target/
```

ignores: each `target` folder in the repo

- With `/`

```gitignore
/target/
```

ignores: only `target` folder in root

6. Wildcard `*`

```gitignore
.db
```

ignores: everything that ends in `.db`

7. Double wildcard `**`

```gitignore
**/logs/
```

ignores: any `logs` folder anywhere

8. Exclusion (negation!)

```gitignore
*.log
!important.log
```

ignores: all `.log` files

BUT:

`important.log` will be tracked

9. Ignoring a specific file in a folder

```gitignore
frontend/.env
```

ignores: only that file

10. Order matters

Git reads from top to bottom

```gitignore
*.log
important.log
```

First, ignore everything
Then, "reverse" for one file

## Project shared `.gitignore` content:

```
# Backend
backend/target/
*.log

# Frontend
frontend/node_modules/
frontend/dist/

# IDE
.idea/
.vscode/

# OS
.DS_Store
Thumbs.db

# H2
*.mv.db
*.trace.db
```

### Backend

1. `backend/target`
    - compiled Java classes (`.class`)
    - application build
    - files generated by Maven.

Why ignore?
- this is the build result, not the code
- you can always recreate it (`mvn clean install`).

2. `.log`
    - files with `.log` extension in entire repo.

Why ignore?
- logs change constantly
- are not util in the repository.

### Frontend

3. `frontend/node_modules`
    - all npm packages (*React*, *Vite*, etc.)

Why ignore?
- huge (hundreds of MB)
- can be recreated:

```bash
npm install
```
.

This is ONE of the most important things in `.gitignore`.

4. `frontend/dist`
    - `frontend/dist` with built frontend (production) application.

Why ignore?
- result of `npm run build`
- we don't keep builds in the repo.

### IDE

5. `.idea/`
    - `./idea` folder
    - IntelliJ settings.

Why ignore?
- each developer may have different settings
- they are not part of the project.

6. `.vscode/`
    - `.vscode/` folder
    - VS Code settings files.

Why ignore?
- each developer may have different settings
- they are not part of the project.

### System

7. `.DS_Store`
    - file created by macOS
    - contains folder metadata.

Why ignore?
- not util in the repository.

8. `Thumbs.db`
    - Windows file.
    - contains Thumbnail cache.

Why ignore?
- some not util junk file.

### H2 DataBase

9. `*.mv.db`
    - main file of H2 database
    - contains data.

Why ignore?
- you don't want to commit to and store data in (f.e. users) repo.

10. `*.trace.db`
    - H2 debug file (H2 logs).

Why ignore?
- not util in repo.
