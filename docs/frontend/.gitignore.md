# `.gitignore`

## Purpose

This file tells Git which files and directories should be ignored (not tracked).

It is mainly used to exclude generated files, build artifacts, logs, and system-specific files that should not be committed to the repository.

## Important notes:

- `.gitignore` only affects untracked files - files already committed will not be ignored
- It supports pattern matching (e.g. `*.log`, `build/`, `temp/*.tmp`)
- You can define exceptions using `!` (e.g. ignore all logs except one)
- `.gitignore` can exist in multiple locations (root, subdirectories, global config)
- It is mainly used to ignore generated files (build artifacts, logs, caches, system files)
= Not everything should be ignored - some files (e.g. database migrations) may be important
- It is not a security feature - sensitive data should never be committed in the first place 

## Example file content:

```
# Compiled source #
###################
*.com // a type of simple executable file
*.class // a file containing Java bytecode that can be executed on the Java Virtual Machine (JVM)
*.dll // containing reusable code and data that can be used by multiple programs at the same time 
*.exe // short for "executable", these files are most commonly used on Windows
*.o // compiled object file produced from source code, used during linking
*.so // shared library used by programs on LInux/Unix systems (loaded at runtime)

# Packages #
############
# it's better to unpack these files and commit the raw source
# git has its own built in compression methods
*.7z // compressed archive in 7-Zip format used for packaging files
*.dmg // macOS disk image file used for distributing applications and installers
*.gz // file compressed using Gzip (often combined with .tar as .tar.gz)
*.iso // disk image file containing a complete filesystem (ISO format)
*.jar // Java archive containing compiled classes and application resources
*.rar // compressed archive in RAR format used for packaging files
*.tar // archive that bundles multiple files and directories (no compression)
*.zip // compressed archive containing multiple files and directories

# Logs and databases #
######################
*.log // log file containing records of application or system activity
*.sql // file containing SQL queries, often used for database dumps or backups
*.sqlite // SQLite database file storing application data in a single file

# OS generated files #
######################
.DS_Store // macOS hidden file storing folder view settings (Finder metadata)
.DS_Store? // variations of .DS_Store files (with extra characters), created by macOS
._* // AppleDouble files storing macOS metadata alongside actual files
.Spotlight-V100 // macOS system directory storing Spotlight search index data
.Trashes // macOS Trash directory storing deleted files for a given volume
ehthumbs.db // Windows system file storing cached thumbnails of images and videos
Thumbs.db // Windows system file storing cached image thumbnails
```
