# 💬 Real-time Chat App

A simple realtime chat app project built for learning purposes.

🟡 Stage: Initialization (Wireframe Design)
📅 Date: 2026-04-19

Currently:

- Backend created (Spring Boot)
- Frontend created (React + Vite)
- Repository and project structure configured

---

🛠️ Technologies

### Backend
- Java + Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- H2 Database

### Frontend
- React
- TypeScript
- Vite

---

📁 Project structure

```
realtime-chat/
 ├── backend/        ← Spring Boot
 ├── frontend/       ← React
 ├── docs/
 │    ├── backend/   ← tutorial/documentation BE
 │    ├── frontend/  ← tutorial/documentation FE
 │    └── shared/    ← API + flow
 ├── .gitignore
 └── README.md
```

---

🚀 Launch

### Backend

```bash
cd backend
./mvnw spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm rundev
```
